# 质量门禁

## 生成前

- 图片角色已明确；没有把标注图或参考人物当成产品事实。
- 已列出人物、体型、服装结构、印花、取景和文案不变量。
- 尺寸要求区分了比例与精确像素。
- 未提供的卖点、材质、认证、功能或营销事实不会被编造。

## 生成后

1. **人物与体型**：脸、发型、年龄感、丰满程度、整体体量、头身比、肩胯宽度、腰线、躯干/腿长和四肢粗细没有漂移。
2. **服装**：颜色、印花尺度和密度、领口、袖长、下摆、松量、口袋、侧缝、腰头、材质、Logo 和配件与产品图一致，没有新增结构。
3. **构图**：人物位置、机位、视线、姿势和上下裁切匹配参考；参考未展示的身体部位没有擅自出现。
4. **合成质量**：手指、肢体连接、服装接触、脚与地面、透视、阴影、光线和色温合理；无参考品牌、水印、标注框、遮罩、辅助线或残留人物。
5. **文件结果**：实际像素、比例、格式、文件名和版本号符合任务；文字逐字核对。

## 失败处理

- 人体比例或取景失败：用原产品/人物权威图重新生成一次，明确“完整人物等比例缩放、严格裁切”，不要纵向拉伸或横向压缩。
- 服装结构失败：把可见结构写成不变量和禁止项；必要时加入另一角度产品图重新生成。
- 只需局部改动：使用当前成品作 edit target，并写明唯一允许改变的项目。
- 第二次仍无法可靠匹配：停止宣称成功，列出具体偏差和需要人工/设计后期处理的项目。

## 报告边界

图片文件存在、尺寸正确或代理目视通过，不等于人物身份、色值、印花重复单元和商品结构已经业务验收。没有人工验收或测量证据时分别标记“视觉初检”或“需人工确认”；不得标记为“完全保真”或“黄金样本”。
