# A+ 参考版式再创作

用最少的用户输入完成一张新版 Amazon A+ 图片。用户只需提供参考图和产品模特图；除非图片角色无法判断，否则不要要求用户重复完整制作规范。

## 输入约定

- 两张图按出现顺序解释：图1为 A+ 版式参考，图2为用户的产品模特图。
- 用户明确指定角色时，以用户指定为准。
- 只有一张图或角色确实无法判断时，简短询问缺失图片或角色。
- 用户未给文案时，文字区域保持干净留白；不要自行编造品牌口号或卖点。

## 工作流

1. 查看两张原图。必要时查看现有的布局分割 PNG 和同名 TXT；它们只作为空间关系说明，不得出现在成品中。
2. 从参考图提炼主体、元素和文字区域的相对位置、比例、层级、留白、视线方向、光影与色彩关系。参考其版式逻辑，但不要复制原品牌、原产品、原人物、原文案或独有标识。
3. 使用内置图像生成工具，以“合成/身份保真编辑”为优先：
   - 参考图是构图、场景和风格参考。
   - 产品模特图是核心主体参考或编辑目标。
   - 产品模特图是人体比例的唯一依据。必须保留模特身份、面部、丰满程度、整体体量、头身比、躯干与腿长比例、自然腰线、肩胯宽度和四肢粗细，以及产品的颜色、结构、材质、Logo和包装特征。参考图只控制姿势、取景、机位和构图，不得继承参考人物的高矮、胖瘦或身材轮廓。
   - 保持产品模特原有的真实身高、骨架和自然身体比例。允许将完整人物等比例缩放以适应画面；禁止纵向拉伸、横向压缩、抬高腰线、延长腿部、缩短躯干、收窄肩胯、减细四肢，也不得放大或缩小头部来强行匹配参考人物。不得把丰满体型改成高挑纤长体型。
   - 不要求保留原图站姿。根据参考版式主动调整模特的站姿、肢体动作、身体朝向、视线与画面位置，使动作自然并服务于产品展示；不要因为改姿势而改变人物身份或产品结构。
   - 严格复制参考图的人物取景范围和裁切位置：参考图展示到身体哪个部位，生成图也必须展示到同一部位，不得擅自扩大为全身或缩小为更近的特写。参考图为半身或大腿中部以上构图时，输出必须在相同部位裁切；参考图没有展示膝盖、小腿或脚部时，输出也不得出现这些部位。参考图为全身时则保留全身取景。
   - 保持真实身高只表示不得改变人体比例，并不表示必须展示完整身体。参考图的头身视觉关系通过姿势、严格匹配的取景范围、完整人物等比例缩放、人物在画面中的占比、机位和透视来实现。如果参考姿势或参考人物的身材与产品模特冲突，以产品模特图的自然身体比例和体量为最高优先级。
   - 重新生成适配用户产品的背景、道具和装饰，并统一透视、光线方向、阴影、色温与接触关系。
4. 最终图片不得包含参考图的品牌、产品、人物、文案、水印，也不得包含布局编号、彩色遮罩、边框或辅助线。
5. 用户提供准确文案时，逐字使用；未提供时留白。对文字准确性没有把握时，优先生成无字底图供后期排版。
6. 检查成品：主体是否变形或换脸；头身比、躯干与腿长比例、腰线、肩胯宽度、四肢粗细、丰满程度和整体体量是否仍与产品模特图一致；是否出现纵向拉伸或横向压缩；新姿势是否自然；人物上下裁切位置与参考图是否一致；是否出现参考图未展示的身体部位；产品结构与 Logo 是否漂移；手指和产品接触是否合理；参考内容是否残留；布局是否清晰。取景或人体比例任一不一致都视为失败，必须针对人物等比例缩放、裁切或身体保真重新生成一次；仍不可靠则说明具体限制，不声称已匹配。

## 默认输出

- 生成一张商业产品摄影风格的 Amazon A+ 横版图片；参考图明显为其他比例时沿用其比例。
- 默认只生成一个成品版本。用户要求多页或多个版本时，每页/每版分别生成。
- 成品用于当前项目时保存到工作区，采用不覆盖原文件的版本化名称，并告知最终路径、所用最终提示词以及使用了内置图像生成模式。

## 最短调用

以下请求均视为完整授权指令：

```text
使用 ecomi-aplus-remix。图1是版式参考，图2是我的产品模特。
```

```text
用这两张图生成新版 A+。
```

若用户补充尺寸、文案、色调或输出目录，只把这些作为覆盖默认值的附加要求。

## 边界

- 只拆布局时使用 `ecomi-aplus-layout`。
- 不承诺像素级复制参考设计，也不复刻其品牌识别内容。
- 不把生成结果冒充真实产品功能、认证、测试数据或用户未提供的营销事实。
